# 网络之网 · 3D 世界模型原型

独立交互原型，用来验证“多层局部网络 + 跨层节点 + 时间演化”的世界模型表达。

## 当前能力

- 5 张局部网络：物理、生物/身体、人际关系、经济、工作/社会
- 跨层节点：人、钱、资源、反馈、风险
- 3D 旋转、缩放、点击节点
- 时间轴 T0-T4：现实接触 → 关系形成 → 局部网络 → 跨网连接 → 规律抽象
- 点击节点后查看关系路径、所属网络、进入模型的时间
- 跨层节点可直接跳转到另一张局部网络
- 搜索节点、聚焦选中关系、显示/隐藏跨层支柱

## 运行

```powershell
npm install
npm run dev
```

默认地址：<http://127.0.0.1:4177>
