## 验证与后续安装约束

入口 `scripts/test-ai-combined-integration.ps1`：原生工具/真实 PowerShell、提示词迁移与隐藏模型共同持久化、历史相对时间/通知、聊天生成态、Markdown 展示、服务路由与 WPF 门禁。真实桌面交互、外部供应商工具调用需另外记录；Cookie 后端没有 Responses 接口时仍应明确失败。

后续正式更新必须同时记录已安装 EXE 与 DLL 的 SHA256、源码提交、工作区脏文件和已验证构建产物。文件版本号及提交字符串不能证明实际 DLL 未被本地修改。若运行文件与已知产物不匹配，先定位并集成补丁或隔离测试，不覆盖正式运行文件。

统一安装包只从合并后的 main 构建；安装后再次核对原生协议、历史界面和隐藏模型字段同时存在，并对照安装前的模型配置与聊天正文。Commit、Merge、本机安装和公开 Release 分别记录。
