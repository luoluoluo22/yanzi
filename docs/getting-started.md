# 快速上手

本指南将一步步带你从零开始使用燕子启动器。即使你从未接触过类似工具，跟着做就能在 10 分钟内上手全部核心功能。

## 第一步：下载与安装

### 下载安装包

前往蓝奏云下载最新版 Windows 安装包：

- 下载地址：[https://wwbnh.lanzout.com/b0pnkaj6j](https://wwbnh.lanzout.com/b0pnkaj6j)
- 提取密码：`62yn`

### 系统要求

- 支持系统：Windows 10 / 11（64 位）
- 无需额外依赖：安装包采用自包含构建（Self-Contained），不需要另外安装 .NET 运行时，双击即可直接运行

### 安装流程

1. 下载后双击 `YanziSetup.exe` 运行安装程序
2. 安装完成后，燕子会自动启动并在系统托盘区（屏幕右下角）显示图标
3. 此时你已经可以使用 `Alt+Space` 唤出搜索栏了

## 第二步：使用燕子搜索（启动器）

燕子搜索是你与燕子交互的主入口，一个全局的搜索栏。

### 唤出与关闭

| 操作 | 方式 |
|------|------|
| 唤出启动器 | `Alt + Space`（也可在设置中改为双击 Alt） |
| 关闭启动器 | `Esc` 或点击窗口外部 |

### 搜索方式

在搜索栏中直接打字即可开始搜索，支持多种输入方式：

- **中文关键词**：输入 `微信` 找到微信
- **拼音首字母**：输入 `wx` 同样能找到微信
- **英文名称**：输入 `chrome` 找到 Chrome 浏览器
- **混合输入**：输入 `jisuanqi` 或 `jsq` 找到计算器

### 键盘操作

| 按键 | 功能 |
|------|------|
| `Up / Down` | 上下切换选中项 |
| `Enter` | 执行选中项 |
| `Esc` | 关闭搜索栏 |
| `Ctrl + K` | 打开选中项的动作菜单（删除、编辑、固定到面板等） |

### 参数化搜索

燕子支持"前缀 + 参数"的搜索方式，让你直接从搜索栏发起带关键词的操作：

- `谷歌 今天的新闻` —— 用 Google 搜索"今天的新闻"
- `gg cloudflare pages` —— 同上，`gg` 是谷歌搜索的简写前缀
- `百度 天气预报` —— 用百度搜索"天气预报"

这些前缀由扩展定义，你可以安装更多搜索类扩展来扩展前缀列表。

### 范围搜索（@ 语法）

如果你把某个扩展固定到了顶部标签栏，可以用 `@别名 关键词` 在它的范围内搜索：

- `@下载 report.pdf` —— 在下载目录中搜索 report.pdf
- `@文件 设计稿` —— 在指定文件夹里搜索包含"设计稿"的文件

## 第三步：使用燕环（鼠标快捷面板）

燕环是为鼠标用户设计的快捷操作面板，让你不用回到桌面就能快速启动常用工具。

### 触发方式

- **长按鼠标右键**：在任意位置长按鼠标右键约 300 毫秒，面板会在光标附近弹出
- **屏幕边缘划动**：将鼠标快速移向屏幕边缘也可唤出（可在设置中配置）

### 添加项目到面板

1. 按 `Alt+Space` 打开搜索栏
2. 搜索到你想添加的应用或扩展
3. 在搜索结果上点击右键
4. 选择"添加到鼠标面板"
5. 下次长按右键时就能看到它了

### 管理面板布局

- **分组**：面板支持多个分组页面，按类别整理项目（如"工作"、"娱乐"、"开发"）
- **拖拽排列**：长按面板中的图标可拖拽调整位置
- **复制 / 剪切 / 粘贴**：面板项目支持复制和移动操作
- **删除**：右键面板项目可选择移除

## 第四步：使用燕幕（桌面小组件）

燕幕让你把重要信息或常用工具以小组件的形式"钉"在桌面上，始终可见。

### 开启燕幕

- 从系统托盘图标右键菜单中开启
- 或在燕子设置页面中启用

### 支持的小组件类型

- **时钟与日期**：在桌面上显示实时时钟
- **系统监控**：CPU、内存等系统状态信息
- **便签**：桌面常驻的笔记小组件
- **快捷入口**：常用应用和网站的一键启动按钮
- **自定义小组件**：开发者可以通过扩展创建自定义内容的小组件

### 自定义小组件布局

- **拖拽定位**：直接拖动小组件到桌面任意位置
- **调整大小**：拖拽小组件边缘调整显示区域
- **显示/隐藏**：在设置中控制哪些小组件可见

小组件的位置和配置会自动保存，重启后保持不变。如果开启了云同步，还会在多台电脑之间同步。

## 第五步：使用燕语（AI 助手）

燕语是燕子内置的 AI 对话助手，你可以用自然语言告诉它你想要什么功能，它会自动帮你生成对应的扩展。

### 使用方式

1. 在燕子中打开燕语面板
2. 用自然语言描述你的需求
3. AI 会生成一个完整的扩展配置（`manifest.json`）
4. 确认后扩展会自动安装并出现在搜索结果中

### 示例对话

| 你说的话 | AI 会生成的扩展 |
|---------|---------------|
| "帮我做一个打开百度的扩展" | 一个 `openTarget` 类型的网页快捷扩展 |
| "做一个搜索 GitHub 的扩展，前缀用 gh" | 一个带 `queryPrefixes` 的参数化搜索扩展 |
| "做一个读取剪贴板内容的工具" | 一个 PowerShell 脚本扩展 |
| "做一个在下载目录搜索文件的扩展" | 一个 `searchProvider` 文件夹搜索扩展 |

### 小贴士

- 描述越具体，生成的扩展越精准
- 生成后可以手动微调 JSON 内容
- 如果对结果不满意，换个说法重新描述即可

## 第六步：配置云同步

云同步让你的扩展、面板布局和个人配置在多台电脑之间自动保持一致。燕子支持两种同步方式，数据都存储在你自己的空间里。

### 方案 A：通过 WebDAV（坚果云）同步

坚果云是国内常用的支持 WebDAV 的网盘，配置简单且免费额度够用。

1. 登录 [坚果云网页版](https://www.jianguoyun.com)，进入"账户信息" -> "安全选项"
2. 在"第三方应用管理"中，点击"添加应用密码"，输入应用名称（如 `yanzi`），生成一个授权密码
3. 打开燕子客户端设置页面，选择 WebDAV 同步
4. 输入服务器地址：`https://dav.jianguoyun.com/dav/`
5. 用户名填写你的坚果云账号邮箱
6. 密码填写刚才生成的**授权密码**（不是你的登录密码）
7. 点击"保存"即可开启同步

### 方案 B：通过 GitHub 同步

如果你有 GitHub 账号，可以把配置同步到一个 GitHub 仓库中。

1. 前往 GitHub，新建一个空仓库（建议命名为 `yanzi-sync`，设为私有）
2. 进入 GitHub Settings -> Developer settings -> Personal access tokens，生成一个包含 `repo` 权限的 Token
3. 在燕子设置中选择 GitHub 同步方式
4. 填写你的 GitHub 用户名、仓库名（`yanzi-sync`）、分支名（`main`）和刚生成的 Token
5. 保存设置，即可实现安全的代码库备份与同步

### 同步范围

以下内容会在设备之间自动同步：

- 已安装的扩展列表和扩展配置
- 燕环（鼠标快捷面板）的布局和分组
- 个人偏好设置

## 第七步：安装与管理扩展

### 从扩展商店安装

1. 在燕子中搜索"扩展商店"或访问网页版商店
2. 浏览或搜索你感兴趣的扩展
3. 点击安装按钮即可一键安装到本地

### 从剪贴板导入

如果你从网上复制了一段扩展的 JSON 配置：

1. 把完整的 `manifest.json` 内容复制到剪贴板
2. 在燕子中粘贴，系统会自动识别并提示导入
3. 确认后扩展立即生效

### 管理已安装扩展

- **搜索**：在启动器中输入扩展名称即可找到
- **编辑**：通过 `Ctrl+K` 动作菜单进入编辑模式
- **删除**：通过右键菜单或动作菜单中的删除选项
- **固定到面板**：右键选择"添加到鼠标面板"快速访问

## 遇到问题？

- **启动器不弹出**：检查燕子是否在系统托盘中运行，确认快捷键没有被其他软件占用
- **搜索结果为空**：等待首次索引完成，或在设置中手动刷新索引
- **同步不生效**：检查网络连接和同步配置中的用户名/密码是否正确
- **扩展无法执行**：先检查 `manifest.json` 格式是否正确，可用任意 JSON 校验工具验证
