# 1. 下载与安装

本指南将介绍如何下载和安装燕子启动器，以及基础系统要求。

## 下载安装包

前往蓝奏云下载最新版 Windows 安装包：

- 下载地址：[https://wwbnh.lanzout.com/b0pnkaj6j](https://wwbnh.lanzout.com/b0pnkaj6j)
- 提取密码：`62yn`

## 系统要求

- **支持系统**：Windows 10 / 11（64 位）
- **独立无依赖**：安装包采用自包含构建（Self-Contained），不需要另外安装 .NET 运行时，双击即可直接运行

## 安装流程

1. 下载后双击运行 `YanziSetup.exe` 安装程序。
2. 安装完成后，燕子启动器会自动在后台运行，并在系统托盘区（屏幕右下角）显示图标。
3. 此时，软件已经准备就绪。
