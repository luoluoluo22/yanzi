# 临时聊天实测记录

2026-10-03，用户已重新加载浏览器助手 0.2.2，本地工作台已接入默认临时模式。

## 实现

- `temporary` 参数默认为 `true`，工作台新建和复用空闲后台页均从临时聊天首页开始。
- 发送前验证实际 UI。空白页显示“临时聊天”和“关闭临时聊天”控件；首次回复后标题消失，当前网页显示 `Save chat`。回复后的检测要求该控件及临时模式参数，不能仅凭 URL 放行。
- 回复完成后再检查模式。检测失败时保留页面供检查，不自动重发或转为正式聊天。
- 工作台不点击 `Save chat`。正式聊天需显式设置 `temporary:false`；已有正式用户页默认不会发送。
- 保留原有标签页复用、指定页面继续、成功后关闭和清理功能。关闭标签页不等于删除本机任务记录。
