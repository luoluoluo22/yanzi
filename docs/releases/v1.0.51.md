# 燕子 Yanzi v1.0.51 更新内容

**✨ 环境变量全程序共享**
- 燕子启动、修改设置以及从密钥保险箱恢复时，将管理的普通环境变量同步到 Windows 当前用户环境变量，供独立的命令行、IDE 和其他软件直接使用。
- 发送 Windows 环境变化通知，使后续启动的程序能读取新值；不再局限于燕子小程序的执行上下文。

**🔐 安全与兼容性**
- 延续博客园专用凭证与燕子内部上下文令牌的隔离。
- 对系统基础环境变量及其他软件已占用的同名变量做冲突保护；删除燕子配置时仅撤销燕子管理且未被外部修改的变量。
- 原始值继续保存在本机 DPAPI 加密区，注意发布到 Windows 用户环境中的副本由 Windows 以常规环境变量形式存放，不具备 DPAPI 加密保护。

**✅ 验证**
- Windows 集成测试验证新增、编辑、删除、外部变量冲突及专用凭证隔离；编译通过。
- 每台设备安装后应重新打开命令行进行新进程读取实测。
