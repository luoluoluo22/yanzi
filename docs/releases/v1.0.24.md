# 燕子 Yanzi Windows v1.0.24

## 核心修复：保持一个燕子主程序

- 基于 v1.0.23 的单进程正式版继续演进，**仅交付 Yanzi.exe**，不再捆绑 Yanzi.Runtime.exe。
- UI、手机通信、后台轮询、调度器、闲时任务和小程序宿主仍由一个燕子进程负责。
- 新安装包和便携版均执行单进程布局校验：若含独立 Runtime 入口则拒绝发布。

## 反重力（Antigravity）流式消息集成

- 内置 `chat.stream`：手机端增量生成快照优先通过加密局域网传送，公网通过已认证 Durable Object 实时回退。
- 临时流式预览不计为持久聊天消息，不把每次 delta 写入 Cloudflare D1；最终回答继续由 `chat.send` 投递。
- 包含反重力 1.3.5 的 `stream-json` 与常驻 Session 小程序源代码，以及 start/update/complete 状态管理。
- 保留 v1.0.23 已发布的 AI 对话并行、剪贴板修复及其他 Windows 改进，不从旧修复分支整体覆盖最新版源码。

## 验证

- Windows Release 编译成功，0 错误。
- RuntimeProfileVerification：Stable / Dev 均通过。
- 反重力 Worker：15/15 通过。

- 单程序的 IPC、手机消息桥、轮询、闲时任务、调度器以及内置 `chat.stream`、`chat.send` 已在台式机上验证。

**说明：** WebView2 浏览器辅助进程与外部 CLI（如 agy.exe、Node）不属于第二个燕子主程序；小程序的用户数据目录不在这次清理范围。手机端停止按钮与公网 WebSocket 回退仍各有独立的后续验收项。
