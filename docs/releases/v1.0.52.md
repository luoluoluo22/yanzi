# 燕子 v1.0.52：跨设备部署生命周期

- 新增独立于燕子进程的 Windows 接收端部署代理，办公室可定期发现正式版本并自主下载、安装和重启。
- 通过正式 GitHub Release 的 SHA-256 摘要验证安装包，支持断点续传及备用镜像、避免重复部署、记录失败原因。
- 新增家里一键发布脚本和通用 GitHub Actions 构建工作流，严格校验 main 提交、版本号、编译、核心回归测试及发行资源完整性。
- 新增设备部署状态文件和回滚显式命令，初始为本机状态与授权远控查询。

接收端首次安装使用 scripts/install-device-deploy-agent.ps1；详细操作见 docs/device-deployment-lifecycle-2026-10-24.md。
