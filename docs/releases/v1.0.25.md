# 燕子 Yanzi Windows v1.0.25

## 自动空间治理

- 新增正式版后台自动维护：首次启动约 2 分钟后检查，此后每 24 小时检查一次，不需要用户手动操作。
- 安装回退快照统一生命周期：默认最多保留近期 2 份，非最新备份达到 14 天后清理；设定 1 GiB 空间预算，超过时优先回收较旧快照。
- 安全回退保护：所有快照创建后至少保留 3 天，最新一份始终保留；所以 1 GiB 是目标预算而非可以不顾数据安全的硬上限。
- 旧双进程 Runtime 的 `versions / shells / bundled / staged` 二进制快照在首次观察后延迟 14 天清理，每组始终保留最新一份，还保护 `runtime.json` 指向的运行回退目标。
- 只删除正式版安装目录中明确受管的程序快照。**不删除** 当前 `Yanzi.exe`、Velopack `packages`、`OpenQuickHost\ExtensionStorage`、小程序、聊天记录、密钥和用户主动备份。
- 正在运行的快照、重新解析点和不可辨认的旧 Runtime 指针会被跳过。发生清理错误时只记录日志，不影响程序启动。

## 验证

- 独立沙箱：验证备份数量、空间预算、3 天保护、14 天观察、旧 Runtime 指针保护和用户数据排除。
- Windows Release 0 错误；正式版和开发版运行身份验证通过。
