# 燕子 Yanzi v1.0.20 — 浣熊 MCP 跨设备部署与公共 Node 环境

本版在 v1.0.19 的功能基础上，完成浣熊 MCP 独立小程序的运行环境整合、设备端口共存和安装恢复。

- **公共 Node 依赖**：浣熊小程序通过 `manifest.requires: ["node>=22.16.0"]` 声明 Node 需求，宿主统一依赖管理器优先复用本机 Node，WinGet 不能安装时使用 Node.js 官方 ZIP、验证 SHA-256 后安装当前用户的便携环境。
- **避免同步大文件**：Node 可执行文件、npm `node_modules`、设备凭证和日志均不随小程序分发；新设备按 `package-lock.json` 自动还原 npm 依赖。
- **避免 MCP 端口冲突**：检测 3766 是否由其他服务占用，允许浣熊转至 3767–3799，同时保留每台设备的独立运行时配置和现有 MCP 服务。
- **环境变量隔离**：阻止从别的 MCP/启动器继承的 `RACCOON_PORT`、`RACCOON_TOKEN`、`RACCOON_ENABLE_SHELL` 等变量覆盖本机浣熊的独立配置。高风险 Shell 权限默认关闭。
- **跨设备工具接入**：修复本地回环桥、PowerShell 5 兼容及基于设备名/ID 的调用路径，支持与笔记本已有的 MCP 服务共存。
- **回归测试**：台式机与笔记本均进行实际安装检查；笔记本自动安装 Node v24.21.0、隔离 npm 恢复和 105 工具清单、ping 端到端校验通过；新增环境变量污染回归测试。

该版本保持既有云同步配置、设备凭证和用户数据不变。小程序安装及用户私人扩展云同步是独立于 GitHub Windows 安装包的分发渠道。
