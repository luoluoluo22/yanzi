## Defect found through Windows runtime execution

\`WebDavCredentialWindow.xaml\` failed with \`XamlParseException: StaticResource Yanzi.Input not found\` before \`YanziUi.ApplyTo\` could install the shared styles. The same pre-initialization pattern existed in \`ProcessPickerWindow.xaml\` and \`PastedTextEditorWindow.xaml\`. Switched all 12 affected shared resource references across those three files to \`DynamicResource\`, then rebuilt and re-ran runtime smoke tests.

Hotkey Confirm being disabled before a shortcut is captured is intentional; the smoke assertion now explicitly verifies this invariant.
