## 已连接的能力
- `lanzou.status`: 查询浏览器连接状态，**不会**把 Edge 在线误判为蓝奏云登录。
- `lanzou.open`: 使用系统默认浏览器打开蓝奏云入口；登录由用户在官方网页完成。
- `lanzou.inspect`: 在 Edge 后台标签提取受信任域名页面结构；返回内容可能只是登录页，绝不当做云盘文件清单。
- `lanzou.browser.read`: 只允许 wait / scroll / scrape，最多 20 步；不给 read 执行 fetch 或脚本。
- `lanzou.browser.act`: 有风险确认的 click/fill 工作流，可作为逐个实测后网盘操作的底层执行器；它不是已经验证的文件管理 API。不可直接操作 iframe 里的跨域文档。
- `lanzou.network.observe`: start/stop/status/snapshot/clear；在 Edge 网络事件中只记录 HTTPS 白名单域名的请求方法、PHP 路径、状态、类型和**非敏感表单字段名**；不记录请求值、Cookie、认证头、查询串、文件体与响应体。
- `lanzou.network.observe` 暂不提供 `probe` 或协议重放：固定 GET 探针连续三次出现宿主超时，即便 AbortController / Promise.race 限时也未能稳定返回，故从对外可用操作中撤下。仅保留已实测稳定的网络观察能力。
- 本机安装 `lanzou-cloud` 小程序导航入口，源码在 `extensions/lanzou-cloud/manifest.json`。

## 安全与运维原则
- 不导出 Chrome/Edge Cookie，不将 Session、Token、密码保存到云同步。
- 敏感网络观察采用显式开关，Service Worker 重启后默认关闭，最多缓存 150 条在内存中。
- 永不记录 URL 的查询串和分享 token 路径；PHP 基本入口名允许记录。
- 破坏性操作必须由燕子 Capability 框架走高风险权限确认，未来 API 重放也一样。
- 不安装运行第三方来源的逆向库；只参考资料并以本机真实观察确认为准。
- 发布或合并前隔离核查现有大量并行未提交改动，避免覆盖其他任务。
