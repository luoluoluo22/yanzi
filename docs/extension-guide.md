# 6. 扩展安装与管理

燕子的核心设计理念是“万物皆扩展”，您可以轻松获取和管理丰富的功能模块。

## 从扩展商店安装

1. 在燕子搜索中输入“扩展商店”并执行，或者直接访问网页版扩展商店。
2. 浏览分类或使用搜索，找到需要的扩展。
3. 点击“安装”按钮，系统会自动识别并一键完成安装，无需重启软件。

## 从剪贴板导入

若您在社区或朋友处获得了一段 `manifest.json` 文本配置：

1. 将该扩展 JSON 配置文本全部复制到系统剪贴板。
2. 激活燕子启动器（`Alt+Space`），直接按下 `Ctrl+V` 粘贴。
3. 系统将弹出导入确认对话框，点击“确认导入”即可立即生效。

## 管理已安装的扩展

- **快速检索**：在启动器中以中文完整名查找对应扩展，或者使用动作菜单。
- **快捷键管理**：在搜索结果上选中对应扩展，按下 `Ctrl+K`，在动作菜单中选择修改配置、查看代码或删除该扩展。

## 常用快捷键速查

| 快捷键 | 功能说明 |
|--------|----------|
| `Alt + Space` | 全局唤出 / 隐藏启动器（核心默认快捷键） |
| `Enter` | 执行/打开当前选中的项目 |
| `Up / Down` | 在搜索结果列表中切换选中项 |
| `Esc` | 关闭启动器界面 |
| `Ctrl + K` | 打开当前选中项的动作菜单 |
| 长按鼠标右键 | 唤出燕环（快捷轮盘） |

## 常见问题排查

- **快捷键失效无法唤出**：请确认燕子托盘图标是否在系统右下角，且该快捷键未被其他常驻软件（如输入法、即时通讯工具等）占用。
- **搜索为空**：若刚安装或导入了扩展，系统需要一至数秒进行索引。也可以在设置页面点击“刷新索引”手动重构。
- **同步配置不生效**：对于 WebDAV，请确保填写的是**应用密码/授权密码**而非登录密码。对于 GitHub，确认 Token 具有 `repo` 权限。
