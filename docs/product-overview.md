# 产品说明

燕子是一款完全免费、开源的 Windows 效率启动器。它把你电脑上的应用、文件、网站、脚本和自动化流程统一整理为"扩展"，通过键盘搜索或鼠标面板一步直达，帮你省去重复的桌面翻找和鼠标点击。

## 燕子能帮你做什么

燕子由三个核心模块组成，各司其职又互相配合：

### 燕子搜索 —— 键盘党的主力入口

按下 `Alt+Space` 即可在屏幕中央唤出搜索栏。直接键入你要查找的项目名称。目前版本仅支持通过**完整的中文名称**进行精确搜索（例如输入 `微信` 搜索微信，输入 `计算器` 搜索计算器）。暂不支持拼音首字母缩写、拼音简拼或英文别名名称，输入非中文完整名称将无法检索出结果。

### 燕环与鼠标面板 —— 鼠标党的效率利器

- **燕环（快捷轮盘）**：在任意位置长按鼠标右键约 300 毫秒，在光标旁弹出的圆形轮盘菜单，通过向对应方向划动鼠标一划即达，适合极高频的几个核心系统操作。
- **鼠标面板（网格面板）**：网格化平铺的快捷启动板，支持分组和自由拖拽管理。用户可以直接点击空白槽位添加项目，或在启动器（燕子搜索）中对搜索到的项目右键点击，选择“添加到鼠标面板”。

### 燕幕 —— 桌面常驻信息层

燕幕是一组可以常驻在桌面上的浮动小组件窗口，始终保持在其他窗口上方。你可以用它来显示时钟、系统监控、便签、快捷入口等信息，省去反复切换窗口查看的麻烦。

小组件可以自由拖拽定位和调整大小，也支持通过扩展自定义内容——开发者可以用扩展系统创建属于自己的桌面小组件。

## 扩展系统：万物皆扩展

燕子的核心设计理念是**万物皆扩展**。所有的功能、程序、网站或自动化流程都可以变成一个独立的扩展（本质上是一个 `manifest.json` 文件），你可以：

- **安装**：从扩展商店一键安装社区贡献的扩展
- **自建**：自己写一个简单的 JSON 文件就能创建扩展
- **分享**：把扩展发布到商店供其他用户使用
- **同步**：扩展随云同步在多台电脑之间自动同步

扩展能力覆盖从简单的"打开一个网页"到复杂的"运行 C# 脚本并弹出自定义界面"，适合从小白到开发者的不同需求层级。

## 云同步：多设备无缝衔接

燕子支持个人私有云盘同步，你的扩展、面板布局和个人配置可以在多台电脑之间自动保持一致。目前支持两种同步方式：

- **WebDAV 同步**（推荐坚果云）：把数据存在你自己的网盘里
- **GitHub 同步**：把数据备份到你自己的 GitHub 私有仓库

所有数据都存储在你自己的空间，不经过任何第三方公共服务器。

## 移动端伴侣

燕子还提供了 Android 伴侣应用，可以接收桌面端推送的通知消息，实现跨设备的信息联动。

## 开源与安全

- **完全开源**：客户端、云端 Worker 代码全部开源，源码可审计
- **隐私第一**：没有任何隐藏上传行为，数据全部保存在你本地电脑和个人网盘中
- **免费无广告**：不设会员门槛，不加第三方广告，只做纯粹的效率引擎
