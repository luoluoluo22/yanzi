# AI 工具执行记录

本轮以现有 `exec_command` / `write_stdin` / `terminate_command` 为基础改造对话展示，不改变模型供应商配置或正式安装。

## 行为

- 一个命令会话对应一张卡片。后续读取输出、写入 stdin 和终止操作更新原卡片；不同对话、不同轮次的记录不会合并。
- 卡片显示命令或参数、工作目录、运行状态、退出码、耗时、交互次数及截断提示。标准输出与标准错误分开显示，可折叠、选择和复制。
- shell 等待期间最多约每 200 毫秒提供一次非消费式预览；模型拿到的仍是原来的完整增量工具结果，预览不重复消费输出。模型思考期间没有新增后台轮询。
- “停止本轮”取消卡片所属对话的当前请求，并沿用 shell 的进程树清理机制，不以当前选中对话为目标。
- `running` 继续显示运行；`completed` 且退出码为零才显示完成；非零退出码、错误、超时、取消和主动停止分别处理。没有退出码的普通工具结果显示“已返回结果”，不推断业务成功。
- 参数错误导致轮询失败时，错误单独显示，不把原命令误报为已退出。轮次结束先清理 shell 会话，再把仍在运行的卡片标记为停止或取消。
- 卡片分别保留最多 32000 字符的 stdout/stderr，超过时保留尾部并累计省略数量。输出窗口在底部时跟随，用户向上阅读后暂停跟随。

## 历史与兼容

`ai-chat-topics.json` 的消息新增 `isToolCall`、`toolName`、`toolFeedback`、`toolExecution`。新字段可缺省，旧普通消息仍按原格式读取。旧版未保存的工具数据不会凭空恢复。

工具结果边界保存记录，避免每个输出片段写盘。重启恢复时，历史中的运行状态改为“执行中断”；不恢复 session ID 或取消委托，不重新执行命令。后续对话上下文使用保存的命令与汇总结果；当前轮次原生 tool call/result 协议仍由 `AiAgentTurnRunner` 管理。

- `scripts/test-ai-tool-experience.ps1`：shell/状态/合并/预览/持久化快照回归、Gemini 兼容回归、AI 契约、宿主编译和 WPF 控件运行测试。
- `scripts/qa-ui-windows.ps1`：干净提交上的 Windows WPF 门禁。执行卡片覆盖深浅主题、输出更新、取消委托、失败状态、选择焦点和折叠；截图在 `%TEMP%/yanzi-tool-execution-ui-qa/`。
- 自动测试使用真实本机 shell 与模拟模型响应。真实模型服务端到端交互、屏幕阅读器完整播报及正式安装版验收仍需单独记录。
