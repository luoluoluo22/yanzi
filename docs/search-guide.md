# 2. 燕子搜索

燕子搜索是系统的键盘效率核心入口，随时全局唤出。

## 唤出与关闭

| 操作 | 方式 |
|------|------|
| 唤出搜索框 | `Alt + Space`（也可以在设置中修改为双击 Alt） |
| 关闭搜索框 | `Esc` 键，或鼠标点击搜索框外部区域 |

## 搜索规则

在搜索框中直接输入你要查找的应用或扩展的完整中文名称，例如输入 `微信` 打开微信，输入 `计算器` 打开计算器，选中后按下回车即可立即运行。

## 键盘快捷键操作

| 按键 | 功能说明 |
|------|----------|
| `Up / Down` | 在搜索出的结果列表中上下切换选中项 |
| `Enter` | 执行/打开当前选中的项目 |
| `Ctrl + K` | 打开当前选中项的“动作菜单”（用于删除、编辑、固定到面板等操作） |

## 参数化与范围搜索

支持通过“前缀关键词 + 空格 + 参数”的组合直接发起带关键词的特定操作，例如：

- `谷歌 今天的新闻` —— 使用 Google 搜索“今天的新闻”
- `百度 天气预报` —— 使用百度搜索“天气预报”

若将扩展固定到顶部标签栏后，可使用 `@别名 关键词` 形式在特定扩展的内部范围进行搜索：

- `@下载 设计稿.pdf` —— 在配置好的下载目录范围内精确查找该 PDF 文件
