# Android 0.2.44：笔记与应用中心网络路径修复

用户报告红米 K70 在 5G、VPN 开启、无 Wi-Fi 时，文件可用但笔记无法连接，应用中心出现 Connection reset。此前仅定位问题，未修改或发布。

应用中心目录、账号应用库、应用定义及 APK 下载，以及宿主小程序 Object Sync 存储，改为优先使用系统默认网络（包含 VPN）。安全读取遇到传输错误时最多再尝试一次物理网络。HTTP 拒绝、响应超限、线程中断和账号会话变化不重试；写入不自动重放，保持 CAS 冲突语义。下载继续流式落盘，备用请求从头覆盖，安装前保留大小、SHA-256、包名、版本和签名校验。存储响应统一使用有界读取，异常路径也关闭连接，重试前后检查同一账号会话。

笔记通过 SDK HostStorage 使用燕子宿主的存储接口，本次更新宿主即可获得网络修复，无需同时更新笔记 APK。

验证结果：

- Java 故障注入：系统路径优先、传输失败切换、有限次数、HTTP 拒绝、会话变化、写入不重放；有界 UTF-8 响应与连接流清理通过。
- Dev 与 Release 构建通过，Release lintVital 通过。
- 模拟器正式包覆盖升级、重复安装、回退和再次升级通过；登录会话、设备标识、偏好、1 MiB 本地文件以及 75 条旧消息保留，消息迁移只执行一次；最终清空合成测试数据并完成启动验证。
- 最新 Dev 包实际小程序云对象读写通过：revision 1 → 2 → 冲突(2) → tombstone(3)，使用独立本地 Worker/D1 与合成账号。
- 正式包：cc.luoluoluo.yanzi.mobile，versionName 0.2.44，versionCode 44，minSdk 26，targetSdk 35；签名证书 SHA-256 与此前正式包一致（8a0ec0b84d1a05edcc89dd020bf81901f9ed7f083887db7c05201c59b31e1ee3）。
