# Android 0.2.46：异步按钮反馈与下载节点选择

## 问题与修复

更新清单已经改为云端 APK 地址，但旧的镜像分支只处理 `github.com` 下载地址。因此镜像被跳过，最后的下载提示却仍写着“降级为直连官方”。这是下载源判断和提示的错误，不能据此认定所有镜像都失效。

- `BusyButton` 统一保存、显示和恢复异步操作状态：按钮禁用、变灰，文本按钮显示处理中，检查更新设置行显示转圈。覆盖检查更新、应用目录刷新、获取/下载应用、局域网重新检测、立即定位上报及设定家的位置。
- 检查更新只有一个在途任务；手动检查加入已有检查时仍显示忙碌并获取手动结果。成功、失败、Dev 无对应发布资产都会释放状态。应用中心处理任务时禁用其他应用操作；结束后恢复。
- 前台/静默更新共用进程内下载锁，防止同时改写同一个 APK 和取消标记。缓存安装校验放到后台并显示准备安装状态，下载过程只在百分比变化时更新 UI。
- `UpdateDownloadNodes` 从云端发布文件名构造同版本 GitHub 官方与 ghfast/ddlc 镜像地址，也保留云端备用物理网络。已经存在的 GitHub 下载地址同样支持镜像。
- 并行读取每条路线最多 32 KiB 的 APK 样本，检测总预算 7 秒、单连接/读取超时 3 秒。只接受正确 HTTP、ZIP 头、完整样本及从零开始的 Range；拒绝 HTML/JSON 错误页。根据样本耗时尝试可用路线，显示实际节点名称，不再使用误导的“降级”提示。
- 正式包下载只接受完整的 HTTP 200，限制 200 MiB，验证长度、发布目标版本、包名、现有证书和清单提供的 SHA256。下载或包校验失败时继续其他通过检测的节点。所有检测失败时保留发布源最后一次实际下载兜底；取消后不发起新下载。
- 更新清单优先系统网络（包含 VPN），失败后尝试物理网络；不再为成功的 VPN 路线先等待一次直接网络失败。

## 实测节点

样本为真实 `android-v0.2.45` 的 APK，而不是历史 Windows 安装器或首页。电脑侧使用 32 KiB 样本 SHA256 与云端样本比较：

| 节点 | 电脑样本 | 最终一加/模拟器 |
| --- | --- | --- |
| 燕子云端 | 1531 ms，APK 样本一致 | 通过；手机按自己的测量选择系统/备用网络 |
| GitHub 官方 | 2812 ms，APK 样本一致 | 通过 |
| ghfast | 5484 ms，APK 样本一致 | 通过 |
| gh.ddlc | HTTP 429 限流 | 同样返回 429，跳过 |
| kkgithub | TLS 主机名证书不匹配 | 已从候选中移除，不关闭证书校验 |

这些是当时网络的连接与样本读取耗时，不是全包持续吞吐或用户红米 5G＋VPN 的速度承诺。手机下载时自己测量；每次最多约 160 KiB 检测流量，仅在实际需要下载新版本时运行。
