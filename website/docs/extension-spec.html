扩展规范

本章详细说明燕子扩展中 manifest.json 的各字段类型、定义范围以及支持的系统运行期权限。

1. 典型声明示例

以下为一个完整的标准搜索引擎前缀传参扩展 manifest 声明：

{
  "id": "google-search",
  "name": "谷歌搜索",
  "version": "0.1.0",
  "category": "搜索",
  "description": "使用默认浏览器快捷进行 Google 搜索。",
  "keywords": ["谷歌", "guge", "google", "gg"],
  "icon": "mdi:search",
  "openTarget": "https://www.google.com",
  "queryPrefixes": ["谷歌", "guge", "google", "gg"],
  "queryTargetTemplate": "https://www.google.com/search?q={query}"
}

2. 属性字典定义说明

字段 Key 类型 是否必填 描述定义
id String 必填 扩展的唯一全局 ID。建议使用小写字母、数字及中划线命名。
name String 必填 展示给用户的名称。
version String 必填 版本号。遵循语义化版本规范（例如 0.1.0）。
category String 选填 类别。例如 工具、搜索、脚本 等。
description String 选填 扩展功能用途的详细描述。
keywords Array 选填 用户搜索该扩展时被命中的关键字列表，支持中文及拼音缩写。
icon String 选填 图标声明。可以是 mdi:search（内置图标）、本地相对路径图片或 Web 链接。
openTarget String 选填 打开目标。配置后，点击扩展会自动打开该本地目录、文件或网页地址。
queryPrefixes Array 选填 在主启动器输入匹配的前缀词列表。
queryTargetTemplate String 选填 前缀搜索的跳转 URL 模板。剩余的搜索关键字会自动替代 {query} 占位符。
runtime String 选填 运行引擎类型。支持 csharp 或 powershell。
entryMode String 选填 执行方式。目前推荐使用 inline（内联代码直接运行）。
permissions Array 选填 申请的特定运行时权限，例如 context.read、clipboard.read。

3. 权限列表声明说明

  • context.read：允许扩展动作读取宿主传入的选中文件路径、当前软件窗口等上下文信息。
  • clipboard.read：允许扩展脚本读取 Windows 系统剪贴板内容。
  • clipboard.write：允许扩展脚本写入/覆盖 Windows 系统剪贴板。
