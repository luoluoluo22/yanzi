快速上手

本章将引导你下载并安装燕子客户端，了解高频使用的基础快捷键，以及如何配置个人多端云同步。

1. 下载与安装

系统运行要求

  • 支持系统：Windows 10 / 11（64位）
  • 无额外依赖：安装包采用自包含构建（Self-Contained），不需要另外下载并安装 .NET 运行时，双击即可直接运行。

2. 快捷键与基本操作

操作行为 默认快捷键 / 触发方式
唤出主启动器 Alt + Space (双击 Alt 可在设置中修改)
中文/拼音检索 直接在启动器内打字，支持首字母拼音缩写
导航选择条目 键盘 Up / Down 上下切换，Enter 执行选中
执行动作菜单 选中项按 Ctrl + K 可查看更多进阶操作
右键面板快捷管理 对条目鼠标右键，可选择删除、编辑配置或固定到顶部
唤出鼠标快捷面板 长按鼠标右键，或在屏幕边缘划动鼠标即可弹出面板

3. 配置多设备云同步

燕子支持个人私有云盘同步，免去了数据被收集到第三方公共服务器的安全忧虑。目前主要支持 WebDAV 和 GitHub 两种同步方案：

方案 A：通过 WebDAV (坚果云) 同步

  1. 登录你的坚果云网页版，进入 “账户信息” -> “安全选项”。
  2. 在 “第三方应用管理” 中，点击 “添加应用密码”，输入应用名称，生成一个授权密码。
  3. 打开燕子客户端设置页面，输入服务器地址 https://dav.jianguoyun.com/dav/，用户名填写你的坚果云账号邮箱，密码填写刚才生成的**授权密码**。
  4. 点击“保存”即可开启同步。

方案 B：通过 GitHub 同步

  1. 前往你的 GitHub 账号，建立一个新的空私有/公有仓库（例如命名为 yanzi-sync）。
  2. 进入 GitHub Settings -> Developer settings -> Personal access tokens，生成一个包含 repo 权限的 Token。
  3. 在燕子中选择 GitHub，填写你的 GitHub 用户名（Username）、新建的仓库名（Repo）、分支名（通常为 main）以及生成的 Token。
  4. 保存设置，即可实现安全的代码库备份与同步。
