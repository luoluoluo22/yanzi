产品说明

燕子是一款完全免费、开源的 Windows 效率启动器，帮你用键盘和鼠标更快地完成日常操作。

燕子是什么

燕子把你电脑上的应用、文件、网站、脚本和自动化流程统一整理为"扩展"，通过键盘搜索或鼠标面板一步直达，帮你省去重复的桌面翻找和鼠标点击。

它由四个核心模块组成，各司其职又互相配合：

  • 燕子搜索：Alt+Space 全局唤出搜索栏，秒搜一切
  • 燕环（鼠标快捷面板）：长按右键弹出网格盘，一划即达
  • 燕幕（桌面信息层）：常驻桌面的浮动小组件，随时可见
  • 燕语（AI 助手）：自然语言对话，一键生成专属扩展

燕子搜索——键盘党的主力入口

按下 Alt+Space 即可在屏幕中央唤出搜索栏。直接打字就能搜到已安装的应用程序、自定义扩展、网页书签或系统命令，支持中文、拼音首字母和英文。

支持的搜索方式

  • 输入 微信 或拼音缩写 wx 打开微信
  • 输入 chrome 或 谷歌浏览器 打开 Chrome
  • 输入 jsq（计算器拼音首字母）打开计算器
  • 输入 谷歌 今天的新闻 直接在浏览器里用 Google 搜索
  • 输入 @下载 report 在下载目录里搜索文件

常用键盘操作

按键 功能
Alt + Space唤出 / 隐藏启动器
Up / Down上下切换选中项
Enter执行选中项
Esc关闭搜索栏
Ctrl + K打开动作菜单（删除、编辑、固定到面板等）

燕环——鼠标党的快捷面板

长按鼠标右键约 300 毫秒，一个网格图标面板会在光标附近弹出。把最常用的应用、网站、脚本放进去，鼠标一划就能触发，不用回到桌面找图标。

触发方式

  • 长按鼠标右键：在任意位置长按鼠标右键约 300ms，面板在光标附近弹出
  • 屏幕边缘划动：将鼠标快速移向屏幕边缘也可唤出（可在设置中配置）

添加和管理项目

  1. 按 Alt+Space 打开搜索栏，找到你想添加的应用或扩展
  2. 在搜索结果上点击右键，选择"添加到鼠标面板"
  3. 下次长按右键时就能看到它了

面板支持多个分组页面，按类别整理项目（如"工作"、"娱乐"、"开发"），并支持拖拽调整位置。

燕幕——桌面常驻信息层

燕幕是一组可以常驻在桌面上的浮动小组件窗口，始终保持在其他窗口上方。你可以用它来显示时钟、系统监控、便签、快捷入口等信息，省去反复切换窗口查看的麻烦。

支持的小组件类型

  • 时钟与日期：在桌面上显示实时时钟和日期
  • 系统监控：CPU、内存等系统状态信息
  • 便签：桌面常驻的笔记小组件，随手记录
  • 快捷入口：常用应用和网站的一键启动按钮
  • 自定义小组件：开发者可通过扩展系统创建任意内容的桌面组件

小组件可以自由拖拽定位和调整大小，位置配置会自动保存并在云同步中同步到其他设备。

燕语——AI 智能助手

燕语是燕子内置的 AI 对话助手。你可以用自然语言描述需求，AI 会自动帮你生成一个可用的扩展，无需手动编写任何代码。

示例对话

你说的话 AI 会生成的扩展
帮我做一个打开百度的扩展网页快捷入口扩展
做一个搜索 GitHub 的扩展，前缀用 gh参数化搜索扩展
做一个读取剪贴板内容的工具PowerShell 脚本扩展
做一个在下载目录搜索文件的扩展文件夹搜索 Provider 扩展

扩展系统：万物皆扩展

燕子的核心设计理念是万物皆扩展。所有的功能、程序、网站或自动化流程都可以变成一个独立的扩展（本质上是一个 manifest.json 文件）：

  • 安装：从扩展商店一键安装社区贡献的扩展
  • 自建：自己写一个简单的 JSON 文件就能创建扩展
  • AI 生成：用燕语描述需求，让 AI 帮你写
  • 分享：把扩展发布到商店供其他用户使用
  • 同步：扩展随云同步在多台电脑之间自动同步

扩展能力覆盖从简单的"打开一个网页"到复杂的"运行 C# 脚本并弹出自定义界面"，适合从小白到开发者的不同需求层级。

云同步：多设备无缝衔接

燕子支持个人私有云盘同步，你的扩展、面板布局和个人配置可以在多台电脑之间自动保持一致。目前支持两种同步方式：

  • WebDAV 同步（推荐坚果云）：把数据存在你自己的网盘里
  • GitHub 同步：把数据备份到你自己的 GitHub 私有仓库

所有数据都存储在你自己的空间，不经过任何第三方公共服务器。

开源与安全

  • 完全开源：客户端、云端 Worker 代码全部开源，源码可审计
  • 隐私第一：没有任何隐藏上传行为，数据全部保存在你本地电脑和个人网盘中
  • 免费无广告：不设会员门槛，不加第三方广告，只做纯粹的效率引擎
  • 移动端伴侣：Android 伴侣应用可接收桌面端推送通知，实现跨设备信息联动
