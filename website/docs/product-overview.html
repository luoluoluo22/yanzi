产品说明

燕子是一款完全免费、开源的 Windows 效率启动器，支持鼠标右键面板呼出、全局拼音搜索，并且可以让 AI 帮你一键生成专属效率工具。

燕子的核心设计理念

燕子当前的核心产品方向是“万物皆扩展”。所有的功能、程序、网站或自动化流程都可以变成一个独立的扩展，你可以随心拼装、拖拽、修改代码，甚至让 AI 帮你编写。

搜索与执行 (Alt + Space) 全局极速唤出，打字秒搜应用、文件或执行快捷扩展，支持中文和拼音缩写。
鼠标快捷面板 (长按右键) 鼠标物理动作唤出，将你最高频使用的操作排布在网格盘上，一划即达。
JSON 声明式扩展 通过轻量级的 manifest.json 声明各项行为，支持前缀搜索及脚本执行。
安全云端同步 数据本地优先，可绑定个人 WebDAV（如坚果云）或 GitHub 仓库自动进行云备份与多端同步。

界面预览与视觉设计

燕子采用精美高保真的玻璃拟态（Glassmorphism）暗色调设计，致力于提供 Windows 平台上最高颜值的操作体验。

开源与安全性

  • 完整开源：燕子的客户端、同步云端 Worker 代码完全开源，源码可见，永无停服和被厂商限制的隐患。
  • 隐私第一：没有任何隐藏上传行为。数据全部保存在你本地电脑的 SQLite 数据库和个人网盘中，绝对安全。
  • 免费无广：项目不设会员门槛，不加第三方广告，不做臃肿功能，只做纯粹的效率引擎。
