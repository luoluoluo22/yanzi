产品说明

燕子是一款完全免费、开源的 Windows 效率工具。它把常用功能放到鼠标边上，让你少点几次鼠标，少找几次文件，少重复几次操作。

燕子是什么

燕子把你电脑上最常用的东西收拢到一个地方：软件、文件、网站、脚本和自己做的小工具。你不用再回桌面找图标，也不用层层点菜单，长按右键就能直接动手。

它主要解决三件事：

  • 更快打开东西：长按右键弹出轮盘菜单，常用操作一划即达
  • 更快做工具：对着 AI 说一句话，就能生成能用的扩展
  • 更安心使用：数据默认存在本地，不用担心上传和丢失

燕子搜索——键盘党的主力入口

按下 Alt+Space 就能在屏幕中央唤出搜索栏。你只要输入几个字，就能快速找到软件、文件或网页。

你可以这样用

  • 输入 微信，直接打开微信
  • 输入 chrome，直接打开浏览器
  • 输入 gg 今天的新闻，直接用搜索引擎找内容
  • 输入 @下载 report，在下载目录里找文件

常用键盘操作

按键 功能
Alt + Space唤出 / 隐藏启动器
Up / Down上下切换选中项
Enter执行选中项
Esc关闭搜索栏
Ctrl + K打开动作菜单

燕环——鼠标党的快捷面板

长按鼠标右键，常用工具会在光标附近弹出来。你把最常用的软件、文件、网站放进去，下次就不用再回桌面找图标。

你可以怎么理解它

  • 像一个鼠标边上的快捷菜单：最常用的东西放在手边
  • 像一个更快的桌面：不用翻桌面找图标
  • 像一个给小白准备的工具抽屉：点一下就能用，不需要记复杂操作

触发方式

  • 长按鼠标右键：在任意位置长按鼠标右键约 300ms，面板在光标附近弹出
  • 屏幕边缘划动：将鼠标快速移向屏幕边缘也可唤出（可在设置中配置）

添加和管理项目

  1. 按 Alt+Space 打开搜索栏，找到你想添加的应用或扩展
  2. 在搜索结果上点击右键，选择"添加到鼠标面板"
  3. 下次长按右键时就能看到它了

面板支持多个分组页面，按类别整理项目，并支持拖拽调整位置。

燕幕——桌面常驻信息层

燕幕是一组可以常驻在桌面上的浮动小组件窗口，始终保持在其他窗口上方。你可以用它来显示时钟、便签、快捷入口等信息，不用切换窗口就能看到。

支持的小组件类型

  • 时钟与日期：在桌面上显示实时时钟和日期
  • 便签：桌面常驻的笔记小组件，随手记录
  • 快捷入口：常用应用和网站的一键启动按钮
  • 自定义小组件：开发者可通过扩展系统创建任意内容的桌面组件

小组件可以自由拖拽定位和调整大小，位置配置会自动保存。

燕语——AI 智能助手

燕语是燕子内置的 AI 对话能力。你只要说一句“帮我做一个什么工具”，它就能帮你生成可用的扩展，不需要懂编程。

你可以这样理解

  • 像跟一个会写工具的助手说需求
  • 像把你的想法直接变成按钮
  • 像给小白一个“不会写代码也能做工具”的入口

扩展系统：万物皆扩展

燕子的核心设计理念是万物皆扩展。你今天想到的一个小动作，都有机会变成一个能直接点的工具。

  • 安装：从扩展商店一键安装别人做好的工具
  • 自建：自己写一个简单的 JSON 文件就能创建扩展
  • AI 生成：用一句话描述需求，让 AI 帮你写
  • 分享：把扩展发布到商店供其他用户使用
  • 同步：扩展可跟着你的配置一起保存到本地或云端

它既适合只想“点一下就完成”的小白，也适合愿意继续深度定制的开发者。

数据与同步

燕子的默认思路是：先把数据放在你自己的电脑里，够用、安心、好理解。

  • 本地优先：配置默认存在本地，不会无缘无故上传
  • 可选同步：如果你想多台电脑一起用，可以再接自己的网盘或仓库
  • 数据归你自己：无论同步还是备份，最终都在你自己的空间里

开源与安全

  • 完全开源：客户端、云端代码全部开源，源码可审计
  • 隐私第一：没有隐藏上传行为，数据默认保存在你本地电脑里
  • 免费无广告：不设会员门槛，不加第三方广告，只做纯粹的效率工具
  • 移动端伴侣：Android 伴侣应用可接收桌面端通知，实现跨设备信息联动
