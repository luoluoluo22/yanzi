AI 扩展生成测试集

这份测试集用于验证 AI 是否能为燕子（Yanzi）生成可导入、可解析、可平稳运行的扩展 JSON 声明。本页定义了基准测试的 10 大核心场景与验收标准。

💡

统一基准要求：
1. AI 只能返回一个完整 JSON 字符串，不能附带多余文字说明，不含 Markdown 块包裹。
2. JSON 必须能被 System.Text.Json 反序列化引擎直接成功解析。
3. 除非特殊界面定制要求，否则不要使用 WPF 原生代码隐藏与事件注册。
4. 优先选择最轻量无风险的写法：能用 openTarget 解决的绝不编写脚本。

测试 1：打开桌面目录

📋

给 AI 的提示词（Prompt）：
请生成一个燕子扩展定义，名字叫“打开桌面”，点击执行后直接打开 F:\Desktop 路径。

验收点与检查指标

  • 必须声明 openTarget 属性。
  • id、name、version、category 字段完整且语义贴合。
  • 禁止引入额外的脚本段或 hostedView 声明。

常见错误模型

生成了 Linux 风格的无意义路径；输出包裹了 Markdown 语法导致无法自动导入。

测试 2：网页搜索前缀扩展

📋

给 AI 的提示词（Prompt）：
请生成一个网页搜索扩展，前缀词为“bing”和“必应”，用户输入关键词后使用默认浏览器打开 Bing 搜索结果。

验收点与检查指标

  • 正确配置 queryPrefixes 数组且至少包含 “bing”。
  • 使用 queryTargetTemplate 配置跳转模板，并在里面包含 {query} 关键字占位符。

常见错误模型

把要搜索的短语写死到了 URL 后面；忘记定义 queryPrefixes 属性。

测试 3：快捷打开系统记事本

📋

给 AI 的提示词（Prompt）：
请生成一个扩展，点击后调用打开 Windows 系统自带的记事本程序。

验收点与检查指标

  • openTarget 填写 notepad.exe。
  • 仅靠系统路径拉起动作，无需使用 PowerShell 脚本。

常见错误模型

硬编码了非公用系统盘的绝对物理路径，导致在其他用户的电脑上无法正常拉起记事本。

测试 4：C# 选中文本回显

📋

给 AI 的提示词（Prompt）：
请生成一个 C# 内联脚本动作扩展，功能是读取鼠标快捷面板传入的文本内容并原样回显，同时在开头额外展示文本字符长度。

验收点与检查指标

  • runtime 必须声明为 csharp，且 entryMode 为 inline。
  • script.source 中包含标准的 public static class YanziAction 定义与 RunAsync 方法。
  • 能正确读取 context.InputText。

测试 5：PowerShell 系统剪贴板读取

📋

给 AI 的提示词（Prompt）：
请生成一个 PowerShell 扩展，运行后读取当前 Windows 系统剪贴板的纯文本内容并输出。若剪贴板为空则返回提示“当前剪贴板无内容”。

验收点与检查指标

  • runtime 为 powershell，entryMode 为 inline。
  • 申请特定只读权限："permissions": ["clipboard.read"]。
  • 通过 PowerShell 脚本的 Get-Clipboard 输出返回值。

测试 6：活动窗口标题读取

📋

给 AI 的提示词（Prompt）：
请生成一个内联扩展，获取当前处于 Windows 前台的活动窗口名称（Title）并返回显示。

验收点与检查指标

  • 使用 csharp 内联脚本。
  • 需要通过 Windows API 的 GetForegroundWindow 与 GetWindowText 声明 P/Invoke 并调用。

测试 7：宿主便签工作区定制

📋

给 AI 的提示词（Prompt）：
请生成一个 hostedView 扩展。界面左半边是一个多行便签输入编辑框，右半边支持预览。程序打开时自动加载本地的旧便签，点击底部保存按钮能写入到本地存储区。

验收点与检查指标

  • 正确配置 hostedView 工作区对象。
  • 根布局按钮的执行动作与绑定属性支持保存与读取，例如使用 loadStorage / saveStorage。
  • XAML 视图内容完全合法，不使用 Avalonia 暂时不兼容的非常规属性。

测试 8：快速翻译工作区

📋

给 AI 的提示词（Prompt）：
请为燕子制作一个具有宿主界面的“翻译工具”。在输入框中输入原文，点击“翻译”按钮能通过内联脚本将译文输出到右侧显示区。目前先用占位字符串代替真实 API 请求。

验收点与检查指标

  • 使用 hostedView，且其类型属于 split-workbench 左右分栏工作台。
  • 设置按钮动作类型 actionType 为 "script"。

测试 9：带参时间戳转换器

📋

给 AI 的提示词（Prompt）：
请生成一个扩展动作，运行后获取当前的系统本地时间，并格式化为 `yyyy-MM-dd HH:mm:ss` 返回，同时要把快捷面板传入的附带参数拼接在后方输出。

验收点与检查指标

  • 利用 C# 内联运行逻辑。
  • 需要做空值判定，防止快捷面板未传入任何选中文本时程序报错崩溃。

测试 10：缺陷规避与故障回归

📋

给 AI 的提示词（Prompt）：
请分析并修复以下 hostedView 损坏扩展 JSON。要求保证“笔记快速保存”功能不变，剔除不合规的属性，只输出修正后可以直接解析的文件。

验收点与检查指标

  • AI 需要自动找出不符合 Avalonia UI 渲染特性的字段并替换。
  • 清理掉不合规范的 XAML 事件绑定函数，使用符合燕子宿主规范的 `saveStorage` 声明。
