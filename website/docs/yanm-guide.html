4. 燕幕（桌面小组件）

燕幕是将信息常驻在桌面上的浮动小组件窗口，保持在其他窗口上方或嵌入桌面背景。

开启燕幕

您可以通过以下两种方式来启用桌面小组件：

  • 托盘图标启用：右键点击系统右下角的燕子托盘图标，选择“开启燕幕”。
  • 设置页面启用：打开燕子主设置，在“桌面组件（燕幕）”选项卡中勾选“启用燕幕”。

支持的小组件类型

  • 时钟与日期：在桌面显示精美的数字/模拟时钟及当前日期。
  • 系统监控：实时展示当前的 CPU 使用率、内存占用率及上传下载网速。
  • 便签：常驻于桌面的快捷记事本，点击即可打字记录临时灵感或计划。
  • 快捷入口：快捷启动指定网页或应用程序的小按钮列表。
  • 自定义小组件：开发者及高级用户可以通过编写 HTML 扩展实现任意自定义样式的组件。

自定义组件布局

  • 拖动位置：鼠标左键长按小组件的空白处，可以直接拖动到桌面的任意位置。
  • 调整大小：将鼠标悬停在小组件的边缘，当指针形状改变时，按住并拖动即可任意调整显示大小。
  • 可见性控制：在主设置中可以单独勾选需要显示哪些小组件，以及隐藏哪些小组件。

小组件的布局位置、大小等所有状态都会被燕子自动记录保存。若开启了云同步，还会在多台电脑间实时同步该布局样式。
