# 看视频小程序 v1.2.0

## 触发规则

- 定时入口：每日 12:00–13:00 与 19:00–20:00 保留右下角“看视频”按钮，点击才打开视频。
- 米家电饭煲联动：**最近 8 小时发生烹饪完成 → 观察到“保温中” → 从“保温中”直接变为“待机中”**，才自动打开最近追看的视频浏览器页面，**不经过按钮、不再次确认**。
- 只看到烹饪完成、单独保温、设备关闭、保温中→离线、离线→待机、烹饪中→待机均不能触发。一次保温结束仅响应一次。
- 观察采用现有本机 Home Assistant 的完成事件（event 实体）和工作状态传感器（sensor 实体），轮询间隔为 20 秒。
- “保温→待机”是按下取消的代理信号，不是实体按键上报：如果设备自己从保温退出至待机、并且仍在 8 小时窗口，也可能触发。只有设备提供独立取消事件时才能做物理按键级别的严格区分。
- 断网或电脑关机期间发生的状态跳变不会被事后重放。如果用户当时就已经在保温，程序启动后读取到近期完成事件和保温状态，仍可识别之后的取消。

## 续播选择

- 不按午间/晚间过滤浏览器历史；从当前电脑 Edge 或 Chrome 近 45 天的真实视频页面中找续播目标。
- 同一腾讯视频电视剧最近 7 天存在多集记录，优先选择该剧最近访问的一集；否则选择最近访问的有效视频页面。
- 排除站点主页和推荐流；不会上传历史记录。仅能证明访问了某页，不能证明具体观看进度或已看完。

## 配置与权限

运行时配置：`rice-cooker-link.json`（仅本机，不提交个人电饭煲 ID）。字段：
```json
{
  "enabled": true,
  "eventEntityId": "event.your_cooker_cooking_finished",
  "statusEntityId": "sensor.your_cooker_status"
}
```
- `enabled:false` 完全禁用电饭煲联动，定时看视频仍有效。
- 使用延时关机小程序已在本机用 DPAPI 加密保存的 Home Assistant 令牌；不存储新的明文密钥、不控制设备。
- 需要燕子宿主持续运行，并可访问 Home Assistant；断开时不阻断定时入口。

## 验收

- 编译测试与“完成→保温→取消 / 重复待机 / 老完成事件 / 断线重连 / 重启烹饪”等状态机测试。
- 真实 Edge 历史验证：《我不是大师》选中第 14 集，而非较早的第 12 集。
- 正式真实按键端到端验收仍依赖下一次实际取消动作，不应人为操作电饭煲来冒险验证。
- debug.log 记录联动信号及实际视频地址；失败不静默弹按钮。

## 回退

Raccoon 的 `fs_transaction` 在 `OpenQuickHost/McpRuntime/raccoon/source-backups/` 下创建原始字节备份。恢复旧版 `main.cs` 与 `manifest.json` 后重启小程序即可回退。
