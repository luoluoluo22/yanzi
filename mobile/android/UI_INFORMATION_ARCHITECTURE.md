# 燕子 Android 信息架构与 UI 约束

> 目标：手机端是“燕子的随身端”，不是把所有功能堆成一个超级入口页。

## 1. 手机端定位

手机端只承接五条稳定业务链。底部导航按当前业务权重排列为：**电脑 → 开发 → AI → 燕幕 → 我的**；默认进入“电脑”：

1. **燕幕**：查看电脑与手机共享的状态、组件和同步结果。
2. **开发**：创建、调试、运行和同步手机小程序；应用中心属于小程序获取/更新的上下文能力。
3. **AI**：用户用自然语言表达任务，AI 在需要时调用燕子已有的数据和设备能力；数据授权属于 AI 上下文。
4. **电脑**：远程使用已连接电脑的聊天、小程序、文件与终端能力。
5. **我的**：账号、同步、权限和版本设置。

新增一级入口前，必须证明它无法自然归入以上业务链；否则不增加新的导航层级。

## 2. 入口唯一归属

- **应用中心**：主入口归属“开发”，用于获取和更新小程序/独立应用。
- **AI 数据接入**：主入口归属“AI”，用于选择数据范围、生成接入提示词、确认和撤销授权。
- **电脑详情**：主入口归属“电脑”；燕幕页可以展示电脑在线状态，但只作为状态摘要并跳转详情。
- **账号与系统权限**：只归属“我的”。

同一业务不得同时在燕幕、开发、AI、电脑、我的多个页面放置同等级入口。

## 3. UI 是否应该存在的判断

一个可见控件至少满足其一：

- 展示真实、会变化的业务状态；
- 执行真实动作；
- 进入该页面所属业务的下一层详情。

以下内容不得作为主 UI：

- 没有点击行为、却长得像按钮/卡片的装饰控件；
- 仅显示内部实现名、文件 key、ID、调试信息；
- 与本页其他入口执行完全相同动作的重复按钮；
- 用硬编码文案伪装成“实时状态”的指标；状态型 UI 必须能追溯到真实数据源；
- 纯营销文案占用大面积首屏；
- 开发者/诊断能力长期占据普通用户页面。

## 4. 页面组织原则

优先顺序固定为：

**当前状态 / 当前任务 → 主操作 → 必要的次级操作 → 详情**

底部 Tab 已经承担页面身份识别，因此一级 Tab 内不再重复放“大标题 + 页面说明”。

而不是：

**标题 → 功能入口 A/B/C/D → 更多入口 → 实际内容**

空数据区域默认折叠；只有有内容或需要用户处理时才出现。

## 5. 当前页面职责

### 燕幕

只展示：
- 燕幕组件状态；
- 云同步状态；
- 展开/收起燕幕。

电脑连接状态不再放在燕幕页，统一归属“电脑” Tab。

不承担应用中心、AI 数据、开发工具等导航职责。

### 开发

开发工具使用扁平的“图标 + 文字”切换项，不使用外围圆角卡片，也不在图标下追加解释文案。

只展示：
- 小程序；
- 应用中心；
- API 文档；
- 手机 JS 终端。

“新建小程序”属于“小程序”工作区，只在小程序页内部出现；应用中心直接进入应用商店，不再使用独立“同步”入口。

当前工作区对应图标和文字使用该功能的强调色，未选中的项目统一使用灰色。

### AI

首要控件必须是实际对话输入。
只保留：
- 对话；
- 历史会话；
- AI 数据授权。

不要把 AI 页做成其他页面的快捷导航器。

### 电脑

“我的电脑”只作为简洁的信息状态展示，不设计成按钮或嵌套指标卡。

聊天、小程序、文件、终端是互斥工作模式，只保留一套选择器；远程操作入口使用扁平的“图标 + 文字”，不加功能描述和额外圆角卡片层级。当前工作区使用对应强调色，其他工作区统一变灰。

聊天界面遵循成熟 IM 的方向性：自己发送的消息靠右并使用明确的发送方强调色，电脑消息靠左并使用中性气泡；消息列表左右保留安全边距，气泡限制最大宽度；系统错误/状态信息居中弱化，不伪装成任一聊天方。

### 我的

只保留：
- 账号；
- 自动同步；
- 悬浮轮盘；
- 通知；
- 无障碍；
- 检查更新。

设备 ID、编译时间、调试日志等不作为常驻普通 UI。

## 6. 产品术语与测试数据

- 面向用户统一使用“**小程序**”，不再显示“扩展”；内部类名、协议字段和兼容 API 可以保留旧命名。
- 自动化、E2E、连接验收产生的测试消息和验证附件不得进入普通用户历史列表；能识别的测试数据应在读取时清理。
- 测试 UI 与诊断入口默认不进入主业务页面。

## 7. 开发验收规则

新增或调整一个可交互 UI 后必须真机验证：

1. 控件可见且没有遮挡/重复；
2. 点击后进入真实目标或执行真实动作；
3. 状态变化能从真实数据源回写 UI；
4. 错误时有可见反馈，不能静默无响应；
5. 临时测试数据/授权/邀请在验收后清理；
6. 不为测试降低 Activity exported、安全授权或权限边界。

未通过以上验证的入口，不进入发布版本。
